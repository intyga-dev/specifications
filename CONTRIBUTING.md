# Contributing

DIV and DEWP are open specifications. Corrections, interoperability findings and implementation
reports are welcome as GitHub issues or pull requests.

Version 1.0.0 is frozen. A change that alters normative behavior, schemas or vectors must be proposed
for a new versioned release. Editorial corrections must clearly state that they do not change wire
format, canonical bytes or verification results.

Please include a minimal reproducible artifact for conformance findings. Changes to canonicalization
or proof verification should include cross-language vectors covering acceptance and refusal cases.
